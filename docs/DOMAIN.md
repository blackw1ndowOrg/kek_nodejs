# Бізнес-домен: вік, зарплати, вартість (Core Domain Logic)

Документація модулів `src/domain/`: розрахунок віку дитини, зарплат персоналу та вартості навчання й харчування.

---

## 1. Принципи

* **Чисті функції.** Жодних залежностей від Express, Prisma чи бази даних: на вхід — числа й дати, на вихід — число. Тому модулі можна викликати з будь-якого сервісу і тестувати без моків.
* **Гроші — лише в копійках.** Усі суми — цілі числа (`Int`). 15 000 грн = `1500000`.
* **Без похибок float.** Відсотки рахуються множенням до ділення: `amount * (100 - percent) / 100`, а не `amount * 0.88`.
* **Помилка — `BadRequestError`.** Невалідні вхідні дані (вік поза 2–5, знижка не з дозволеного списку, кількість дітей поза 0–20) не «виправляються» мовчки, а кидають `BadRequestError` з `src/errors/AppError` з поясненням (автоматично дає 400 Bad Request на рівні API).
* **Бізнес-значення — параметрами.** Ціни, знижки, ставки, поріг доплати й робочі дні передаються у функцію окремими параметрами (значення з таблиці `Setting`). У кожного параметра є значення за замовчуванням з ТЗ, тож виклик без них рахує за базовими цінами. Константами в коді лишились лише межі віку `MIN_AGE`/`MAX_AGE` (експортуються для інших модулів) і технічні числа формул (`PERCENT_BASE`, `MONTHS_PER_YEAR`).
* **Валідацію налаштувань робить Zod** на рівні сервісу налаштувань; domain перевіряє лише власні вхідні дані (вік, знижку, кількість дітей).

## 3. Вік (`age.js`)

### `ageOnSeptemberFirst(birthDate, targetYear) → number`

Повертає кількість повних років дитини на 1 вересня року `targetYear`.

Вік рахується саме на 1 вересня, щоб дитина не «переростала» свою групу посеред навчального року: якщо в жовтні їй виповнилось 4, вона до кінця року лишається в групі трирічок.

| Параметр | Тип | Опис |
| --- | --- | --- |
| `birthDate` | `Date` або `'YYYY-MM-DD'` | Дата народження |
| `targetYear` | ціле число | Рік, на 1 вересня якого рахуємо вік |

Розрахунок іде в UTC (`getUTCFullYear`, `getUTCMonth`, `getUTCDate`), тож результат не залежить від часового поясу сервера.

**Помилки (`BadRequestError`):** некоректна дата; дробовий `targetYear`; дата народження пізніша за 1 вересня `targetYear`.

```javascript
const { ageOnSeptemberFirst } = require('../domain/age');

ageOnSeptemberFirst('2022-09-01', 2026); // 4 — день народження саме 1 вересня
ageOnSeptemberFirst('2022-09-02', 2026); // 3 — ще не виповнилось
ageOnSeptemberFirst('2020-02-29', 2026); // 6 — високосний рік
```

## 4. Зарплати (`salary.js`)

Усі функції повертають суму за місяць у копійках. `n` — кількість дітей у групі, ціле число від 0 до 20. Ставки й поріг — необов'язкові параметри, у формулах нижче — значення за замовчуванням.

| Посада | Формула | Функція |
| --- | --- | --- |
| Вихователь | 200 000 · n + 300 000 · max(0, n − 12) | `educatorSalary(n, ratePerChild = 200000, extraPay = 300000, threshold = 12)` |
| Помічник вихователя | 2 000 000 + 300 000 · max(0, n − 12) | `assistantSalary(n, baseSalary = 2000000, extraPay = 300000, threshold = 12)` |
| Викладач гуртка | 4 000 000 (40 000 грн), фіксовано | `clubTeacherSalary(salary = 4000000)` |
| Менеджер | 8 000 000 (80 000 грн), фіксовано | `managerSalary(salary = 8000000)` |

Доплата понад 12 дітей нараховується **на додачу** до базової ставки: 13-та дитина коштує вихователю 2 000 + 3 000 = 5 000 грн.

**Помилки (`BadRequestError`):** `n` не ціле, менше 0 або більше 20.

| n | Вихователь | Помічник |
| --- | --- | --- |
| 0 | 0 | 20 000 грн |
| 10 | 20 000 грн | 20 000 грн |
| 12 | 24 000 грн | 20 000 грн |
| 13 | 29 000 грн | 23 000 грн |
| 20 | 64 000 грн | 44 000 грн |

## 5. Вартість для батьків (`pricing.js`)

### 5.1. Формули

Ціни, знижки й робочі дні — необов'язкові параметри; у формулах — значення за замовчуванням.

| Функція | Формула | Помилки (`BadRequestError`) |
| --- | --- | --- |
| `tuitionMonthly(d, tuition = 1500000, discountLevels = [10, 20, 30])` | 1 500 000 · (100 − d) / 100 | `d` не 0 і не з `discountLevels` |
| `mealPerDay(age, basePerDay = 30000, perExtraYear = 10000)` | 30 000 + 10 000 · (age − 2) | `age` не ціле або поза 2–5 |
| `mealMonthly(age, days = 21, basePerDay, perExtraYear)` | `mealPerDay(age)` · days | `days` не ціле або від'ємне |
| `monthlyTotal(age, d, tuition, discountLevels, basePerDay, perExtraYear, workingDays = 21)` | `tuitionMonthly(d)` + `mealMonthly(age)` | як у складових |
| `yearlyTotal(age, d, tuition, discountLevels, yearlyDiscountPercent = 12, basePerDay, perExtraYear, workingDaysPerYear = 252)` | `tuitionMonthly(d)` · 12 · (100 − 12) / 100 + `mealPerDay(age)` · 252 | як у складових |

### 5.2. Правила

* **Знижки (10/20/30%) діють лише на навчання.** На харчування — ні: це окремо перевірено тестом для кожної дозволеної знижки.
* **Річна оплата** дає знижку 12% на навчання; на харчування знижка не діє (відповідно до ТЗ).
* **Робочі дні:** 21 на місяць, 252 на рік за замовчуванням (параметри `workingDays`, `workingDaysPerYear`). Для конкретного місяця можна передати фактичну кількість днів.

### 5.3. Ціна харчування за віком

| Вік | За день | За місяць (21 день) |
| --- | --- | --- |
| 2 | 300 грн | 6 300 грн |
| 3 | 400 грн | 8 400 грн |
| 4 | 500 грн | 10 500 грн |
| 5 | 600 грн | 12 600 грн |

### 5.4. Контрольний приклад із ТЗ

Дитина 4 роки, знижка 20%:

| | Розрахунок | Сума |
| --- | --- | --- |
| Навчання за місяць | 15 000 · 0,8 | 12 000 грн |
| Харчування за місяць | 500 · 21 | 10 500 грн |
| **Разом за місяць** | `monthlyTotal(4, 20)` | **22 500 грн** (`2250000`) |
| Навчання за рік | 12 000 · 12 · 0,88 | 126 720 грн |
| Харчування за рік | 500 · 252 | 126 000 грн |
| **Разом за рік** | `yearlyTotal(4, 20)` | **252 720 грн** (`25272000`) |

```javascript
const { monthlyTotal, yearlyTotal } = require('../domain/pricing');

monthlyTotal(4, 20); // 2250000 копійок = 22 500 грн
yearlyTotal(4, 20); // 25272000 копійок = 252 720 грн
```

## 6. Як використовувати в сервісах

Domain-функції не знають про базу: сервіс дістає дані, перетворює їх на числа й викликає формулу.

```javascript
const { ageOnSeptemberFirst } = require('../../domain/age');
const { monthlyTotal } = require('../../domain/pricing');

async function getMonthlyBill(childId, academicYear) {
  const child = await childrenRepository.findById(childId);
  const age = ageOnSeptemberFirst(child.birthDate, academicYear);
  return monthlyTotal(
    age,
    child.discountPercent,
    settingsService.get('TUITION_MONTHLY'), // кеш налаштувань, без запиту до бази
    settingsService.get('DISCOUNT_LEVELS'),
    settingsService.get('MEAL_BASE_PER_DAY'),
    settingsService.get('MEAL_PER_EXTRA_YEAR')
  ); // копійки
}
```

Помилки невалідних даних автоматично кидають `BadRequestError` і повертають клієнту `400 Bad Request`.

## 8. Відкриті питання до замовника

Поки відповіді немає, діє поточна реалізація:

| Питання | Поточне рішення |
| --- | --- |
| «+5 000 за кожну дитину після 12» — на додачу до 2 000 чи замість? | На додачу |
| Скільки днів харчування в конкретному місяці? | 21 за замовчуванням; фактичну кількість можна передати в `mealMonthly` |
| Чи оплачується навчання влітку при річній оплаті? | Так, 12 місяців |
| Чи можуть ціни й зарплати змінюватись адміном? | Так: сервіс бере значення з таблиці `Setting` і передає їх параметрами |
