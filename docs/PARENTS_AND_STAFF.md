# Модулі Parents та Staff (API Документація)

Цей документ описує роботу ендпоінтів для керування батьками (`parents`) та співробітниками (`staff`).

---

## 1. Модуль Parents (`/api/v1/parents`)

Доступ мають ролі: **`ADMIN`**, **`MANAGER`**.

### Ендпоінти:
| Метод | Шлях | Опис | Ролі |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/v1/parents` | Створення батьків (+ опціонально акаунт User) | ADMIN, MANAGER |
| `GET` | `/api/v1/parents` | Список усіх батьків (пошук за ім'ям/телефоном) | ADMIN, MANAGER |
| `GET` | `/api/v1/parents/:id` | Картка батьків з прив'язаними дітьми | ADMIN, MANAGER |
| `PATCH` | `/api/v1/parents/:id` | Оновлення ПІБ, телефону або боргу | ADMIN, MANAGER |
| `DELETE` | `/api/v1/parents/:id` | Видалення картки батьків | ADMIN, MANAGER |

### Приклад запиту створення (POST):
```json
{
  "fullName": "Іваненко Петро Олексійович",
  "phone": "+380501234567",
  "debt": 0,
  "user": {
    "email": "petro@example.com",
    "password": "Password123!"
  }
}
```

> **Правила безпеки:**
> 1. Неможливо видалити батьків, якщо у них є непогашений борг (`debt > 0`). Сервер поверне помилку `409 Conflict`.
> 2. Неможливо видалити батьків, якщо активна дитина в садку залишиться без жодних інших зареєстрованих батьків (захист від створення дітей-сиріт у системі). Сервер поверне помилку `409 Conflict`. Якщо у дитини є інший зареєстрований батько, видалення дозволено.

## 2. Модуль Staff (`/api/v1/staff`)

### Посади працівників (`type`):
* `EDUCATOR` (Вихователь)
* `ASSISTANT` (Помічник вихователя)
* `CLUB_TEACHER` (Викладач гуртка)
* `MANAGER` (Менеджер)

### Ендпоінти:
| Метод | Шлях | Опис | Ролі |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/v1/staff` | Реєстрація працівника (+ акаунт User) | ADMIN, MANAGER |
| `GET` | `/api/v1/staff` | Список працівників (фільтр по type, isActive) | ADMIN, MANAGER, TEACHER |
| `GET` | `/api/v1/staff/:id` | Інформація про працівника, його групи та гуртки | ADMIN, MANAGER, TEACHER |
| `GET` | `/api/v1/staff/:id/salary` | Розрахунок заробітної плати (доменна логіка) | ADMIN, MANAGER |
| `PATCH` | `/api/v1/staff/:id` | Оновлення ПІБ, посади або статусу активності | ADMIN, MANAGER |
| `DELETE` | `/api/v1/staff/:id` | Видалення працівника | ADMIN, MANAGER |

### Розрахунок заробітної плати (`src/domain/salary.js`):
Ендпоінт `GET /api/v1/staff/:id/salary` використовує функції доменного шару:
* **`EDUCATOR`**: 2 000 грн за дитину у групі, доплата +3 000 грн за кожну дитину понад 12 (у копійках: `200_000 * n + 300_000 * max(0, n - 12)`).
* **`ASSISTANT`**: базова ставка 20 000 грн, доплата +3 000 грн за кожну дитину понад 12 (`2_000_000 + 300_000 * max(0, n - 12)`).
* **`CLUB_TEACHER`**: фіксована ставка 40 000 грн (`4_000_000` копійок).
* **`MANAGER`**: фіксована ставка 80 000 грн (`8_000_000` копійок).
* Якщо працівник неактивний (`isActive: false`), зарплата становить `0`.

> **Правила безпеки:**
> 1. Неможливо деактивувати (`isActive: false`) або змінити посаду (`type`) співробітника, який закріплений за діючою групою чи гуртком. Повертається `409 Conflict`.
> 2. Неможливо видалити закріпленого співробітника. Повертається `409 Conflict`.
> 3. При зміні `type` через PATCH автоматично синхронізується пов'язана роль `User.role` (`MANAGER` або `TEACHER`) та повертається клієнту у відповіді.
